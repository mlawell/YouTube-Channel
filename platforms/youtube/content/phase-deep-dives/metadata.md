# Metadata — Phase Deep Dives

Generated by `tools/scripts/build_phase_scripts.py`. One block per episode, ready to paste at upload.

**Two things must be resolved before any of these are published:**

- `[CART: ...]` — the description promises a timed cart run. If the run has not been driven, that line comes out of the description as well as the script.
- `[RESIDENT: ...]` — same for the resident line. Promising it in the description and not delivering it in the video is worse than not mentioning it.

Titles lead with the search term, per the flagship's rule. A per-phase video is a long-tail play: far fewer searches than "phases explained", far higher intent — nobody types a specific phase number unless they are seriously considering it.
