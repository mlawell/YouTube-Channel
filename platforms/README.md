# Platforms

Per-platform operational playbooks, content, and assets for **Beach Homes Social
Studio**. Shared, platform-neutral knowledge lives in
[`../knowledge/`](../knowledge/README.md); brand identity and canonical contact
details live in [`../brand/`](../brand/README.md).

Each platform folder follows the same layout:

```
<platform>/
  README.md     # positioning, account status, cadence, and how-to for this platform
  content/      # drafts, captions, scripts, post copy (organized by campaign/date)
  assets/       # platform-specific exports: banners, thumbnails, cover art, clips
```

## Workflow

1. Learn the strategy in [`../knowledge/`](../knowledge/README.md).
2. Apply brand identity from [`../brand/`](../brand/README.md).
3. Draft platform copy in `<platform>/content/`.
4. Produce media with [`../tools/`](../tools/) and export to `<platform>/assets/`.
